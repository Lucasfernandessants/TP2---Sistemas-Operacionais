# TP2---Sistemas-Operacionais
Simulador de gerenciamento de memória desenvolvido em C para a disciplina de Sistemas Operacionais. O projeto implementa mecanismos de paginação, gerenciamento de quadros de memória e algoritmos de substituição de páginas, permitindo simular e analisar o comportamento da memória durante a execução de diferentes sequências de acessos.
